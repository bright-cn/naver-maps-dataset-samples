<h2>数据集中包含的部分数据点：</h2>

* ```url```：地点在 Naver 地图上的 URL
* ```place_id```：每个地点的唯一标识符
* ```place_type```：地点类型，例如餐厅、住宿、景点或医院
* ```name```：商家或地点名称
* ```category```：地点的主要类别
* ```all_categories```：地点关联的所有类别
* ```category_code```：Naver 用于主要类别的内部代码
* ```address```：韩文完整道路名称地址
* ```address_en```：罗马字母拼写（英文）的道路地址
* ```postal_code```：5 位韩国邮政编码
* ```region```：地点所在的韩国行政区
* ```lat```：地点纬度
* ```lon```：地点经度
* ```business_status```：商家的当前状态，例如营业、停业或休息日
* ```open_hours```：每周营业时间
* ```menu```：包含价格的结构化菜单
* ```reviews_count```：访客评论和博客评论总数
* ```visitor_review_score```：访客评论的平均评分
* ```visitor_review_keywords```：评论中最常提及的亮点，例如口味或服务
* ```nearest_transit```：最近的公共交通站点及其距离

以及更多内容。

<h2>Naver 地图数据集有哪些使用场景？</h2>

<h3>1. 本地商业情报</h3>
企业使用 Naver 地图数据集，按类别和地区绘制韩国各地商家的分布图。借助地址、坐标、地区和营业时间等信息，公司可以评估本地市场规模、发现覆盖空白，并创建精准的潜在客户名单。

<h3>2. 评论与声誉追踪</h3>
品牌和本地营销人员通过分析评论数量、访客评论评分和评论关键词，衡量公众对各地点的看法。这些信息有助于了解韩国顾客最重视哪些方面，以及商家与附近竞争对手相比表现如何。

<h3>3. 位置与选址</h3>
零售、餐饮和房地产团队使用地点类别、坐标及附近公共交通数据来评估位置。比较各地区的竞争对手密度和菜单价格，有助于决定新分店的开设地点及其定价方式。
